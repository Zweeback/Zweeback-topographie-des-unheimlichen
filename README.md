# Topographie des Unheimlichen

Historically grounded dark-folklore third-person RPG in Godot 4.7.1, set around the Reinhardswald and adjacent North Hessian / Weserbergland cultural landscape.

## Product thesis

The game does not treat tourist fairy-tale labels as historical fact. It makes visible how real landscape, historical use, oral tradition, literary editing, later tourism, personal memory and explicit creative adaptation overlap.

## Evidence classes

- **A** Primary source
- **B** Reliable research
- **C** Regional tradition
- **D** Tourist/popular attribution
- **E** Creative synthesis
- **O** Oral history

Every historical/lore claim used in production must carry one provenance state.

## Current vertical-slice target

- Third-person exploration
- Gottsbüren / Sababurg / Trendelburg / Mühle / Wolkenbruch / Gieselwerder placeholder region
- Seven-axis morality: Mercy, Greed, Truth, Fear, Pact, Renown, Corruption
- Quest chain: `Die Hostie und der Name`
- Deterministic quest state machine; no moral farming or repeatable irreversible choices
- Data-driven location and legend catalog
- Local-first bounded AI-NPC adapter; LLMs never mutate game state directly
- Authored fallbacks for all critical dialogue
- Godot 4.7.1 validation and headless test gates

## Research rule

Historical truth, plausible reconstruction, documented regional legend, later tourist framing and invention must never be silently merged.

## Status

This repository is the new canonical home. Existing prose, research dossiers, Quality Cycle 01 results and recoverable Godot source are migration inputs, not automatically trusted truth.
